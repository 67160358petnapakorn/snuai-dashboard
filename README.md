# SNUAi – Smart Nursery Safety AI Dashboard

Dashboard เชิงเล่าเรื่องสำหรับวิชา **Business Idea Creation**
ระบบ AI CCTV ตรวจจับเด็กหกล้ม พื้นที่อันตราย และของมีคม พร้อมแจ้งเตือนผู้ดูแลแบบ Real-time

> ข้อมูลทั้งหมดเป็นข้อมูลจำลอง (mock data) เพื่อการนำเสนอ

**เปิดดูบนเว็บ:** https://67160358petnapakorn.github.io/snuai-dashboard/#s3

## เนื้อเรื่อง (พรีเซนต์ 3 นาที)
1. ปัญหา – เหตุเสี่ยงเกิดเมื่อไรและแบบไหน
2. AI เห็นอะไร – ความแม่นยำและพื้นที่เสี่ยง
3. ผลลัพธ์ – เวลาตอบสนองลดลง
4. ธุรกิจ – รายได้ ต้นทุน จุดคุ้มทุน
5. ลูกค้า – Funnel Awareness → Advocacy

## โครงสร้าง
```
index.html          หน้า Dashboard (ไฟล์เดียว เปิดได้ทันที)
data/*.csv          ข้อมูลที่ใช้ (นำเข้า Power BI / Excel ได้)
.nojekyll           ให้ GitHub Pages เสิร์ฟไฟล์ตามปกติ
```
ข้อมูลที่กราฟใช้อยู่ในตัวแปร `D` ใน `index.html` และมีสำเนาเป็น CSV ในโฟลเดอร์ `data/`
หากแก้ตัวเลข ให้แก้ทั้งสองที่ให้ตรงกัน

## ตารางกรอบ Dashboard
| บท | คำถาม | ตัวชี้วัด | กราฟ |
|---|---|---|---|
| 1 ปัญหา | เหตุเสี่ยงเกิดเมื่อไรและแบบไหน | จำนวนเหตุ, ชั่วโมงสูงสุด | แท่ง |
| 2 AI | AI แม่นพอหรือไม่ | False Alarm %, พื้นที่เสี่ยง | เส้น, แท่งแนวนอน |
| 3 ผลลัพธ์ | ตอบสนองเร็วขึ้นเท่าไร | เวลาตอบสนองเฉลี่ย | เส้น |
| 4 ธุรกิจ | รายได้คุ้มต้นทุนหรือไม่ | รายได้, ต้นทุน, กำไร | แท่งแนวนอน |
| 5 ลูกค้า | ลูกค้าหลุดที่ขั้นไหน | Conversion แต่ละขั้น | Funnel |
